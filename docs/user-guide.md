# 使用说明：导航与任务操作

本文介绍 2026 年 11 月这一轮更新后的导航结构和任务操作方式。部署和备份请看 [`deployment.md`](./deployment.md)。

## 升级前先备份

这一轮更新**没有改动数据库结构**（没有新的数据库迁移），已有数据不会被改写。但升级前仍建议先做两份备份：

1. **JSON 导出**：设置 → 通用 → 导出数据 → 导出 JSON。
2. **数据库完整备份**：见 `deployment.md` 第五节（`pg_dump` 加 `docker compose cp`）。

然后按部署说明更新代码，并运行 `docker compose up -d --build`。

## 侧边栏

侧边栏共七组，顺序如下：

| 分组           | 内容                                                                     |
| -------------- | ------------------------------------------------------------------------ |
| 概览           | 仪表盘（另有个人统计、效率，规划中）                                     |
| 工作与事务     | 工作、业务、行政事务、重要截止日期、项目、看板、甘特图、目标             |
| 任务           | 全部任务、四象限矩阵、已排程任务（规划中）、回收站                       |
| 个人成长与生活 | 成长、学习、健身、技能、个人生活、日历、角色、经验值、奖励（以及统计等） |
| 资料与记录     | 文件（规划中；今后还会有笔记、参考资料）                                 |
| 财务           | 资产总览、账户                                                           |
| 系统与自动化   | 自动化规则、通知、设置                                                   |

- 点击分组标题可以**展开或收起**这一组。浏览器会记住你的选择，刷新后保持不变；打开某一组里的页面时，这一组会自动展开。
- 标着 P2 / P3 的项目表示属于第 2 / 第 3 阶段，目前只有说明页。
- 「目标」会打开「成长」页面里的成长目标。

## 项目与领域

- **在项目里新建任务**：任务自动使用项目的领域。如果你在快速添加里写了 `@领域`，就以你写的为准。
- **把任务移到项目**：如果任务还没有领域，就使用项目的领域；已经有领域的任务保持不变。
- **你手动改过的领域不会被覆盖**：之后再编辑任务的其他内容，领域都不会变。

### 未分配项目的任务

「全部项目」页面下方有「未分配项目的任务」区域，列出还没有归入任何项目、尚未完成的任务。有两种方式把它们归入项目：

- **拖动**：按住任务左侧的拖动手柄，把它拖到上方的项目卡片上。
- **菜单**：用任务右侧的「移到项目…」选择项目，适合键盘和触屏操作。

移动只是给原来的任务设置所属项目：标签、子任务、依赖关系、日期和历史记录都会保留，不会新建一个任务。

## 全部任务：直接编辑

每个任务下方有一行属性，点一下就能修改，不用打开完整的编辑面板：

- **状态、优先级、领域、项目**：点击当前值，从菜单里选择。子任务跟随上级任务的项目，所以子任务不显示「项目」。
- **开始日期、截止日期**：直接选择日期；清空即为不设置。

修改会立即显示，并保存到服务器，刷新后仍然有效。如果修改不合法（例如开始日期晚于截止日期），界面会恢复原值并给出提示。点击任务标题，仍然会打开完整的编辑面板。

**开始日期的默认值**：在任务列表里用快速添加新建的任务，开始日期默认是今天。这个默认值只用于新建任务；已有任务的开始日期不会被批量改动，编辑其他字段时也不会被设置。

> 新任务从今天开始，所以截止日期不能早于今天。如果要补录一个截止日期已经过去的任务，请先修改或清空它的开始日期。

## 子任务

- 用键盘时，`j` / `k` 可以在任务之间移动，展开后的子任务也包括在内。
- 有子任务的任务，左侧会出现一个小箭头。点击箭头可以**展开或收起**子任务；任务右侧的 `1/3` 表示已完成 1 个、共 3 个。
- 展开后，子任务同样可以直接编辑和完成。
- 完成上级任务时，如果还有未完成的子任务，确认完成的窗口会提供「同时完成 N 个未完成的子任务」，默认勾选，可以取消勾选。已取消的子任务不会被改变。

## 完成任务：确认完成日期

完成任务时，会先弹出「确认完成」窗口。以下操作都会弹出这个窗口：点击圆形勾选框、按 `x` 键、点详情面板的「完成」、在状态菜单里选择已完成类状态、在看板里拖到已完成列。

- 默认是**今天**，按当前时间记录。窗口打开时焦点在「确认完成」上，所以用键盘时按 `x` 再按 `Enter`，就能按今天完成。
- 可以选择**今天以前**的日期（也有「昨天」快捷按钮），用来补录实际完成的时间。补录的任务会记为那一天完成，在列表、仪表盘和项目进度里都按那一天计算。
- 不能选择未来的日期。
- 点「取消」或按 Esc，任务**不会**被标记为完成。
- 已经完成的任务不会被重新记录，原来的完成时间保持不变。

> 经验值（XP）在你确认完成的那一刻记入，所以补录的任务，其经验值会出现在当天的经验记录里；自制力仍然按确认的完成日期判断是否按时。
