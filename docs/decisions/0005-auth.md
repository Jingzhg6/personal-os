# 0005 — Better Auth with email + password

**Decision.**

- Better Auth, self-hosted, Drizzle adapter, email + password (min. 8 characters).
- Sign-up can be closed with `AUTH_ALLOW_SIGNUP=false` once the owner's account exists.
- Better Auth's default rate limits stay on (sign-in/sign-up: 3 requests / 10 s per IP).
  When deployed behind a reverse proxy, configure `advanced.ipAddress` so the client IP is used.
- Login is independent of calendar OAuth: calendar accounts (Phase 2) are separate connections
  with their own scopes, never the login identity.
- No Google login for now (accessibility from mainland China); passkeys / OAuth can be added
  as Better Auth plugins later.
- New users trigger `user.registered`; modules provision defaults from that event.
